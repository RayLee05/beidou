# 位同步与导航电文解调：代码与验证入口

更新日期：2026-10-26。基于 GitHub `527e497` 更新，优先修正同步及电文时间有效性。既有捕获、跟踪报告的本地修改保留；本次日志作为后续实验报告的数据依据。

## 本次代码改动

| 文件 | 行为 |
| --- | --- |
| `rtl/sync/nh_bit_sync.sv` | 从实际首个 `dump_ms` 建立 NH 相位；缺号、重复号、不完整窗口和标签回绕时撤销同步、丢弃旧历史并重新搜索。 |
| `rtl/sync/d1_frame_sync.sv` | 检查相邻输入位的起点标签相差 20；中断时取消旧译码及时间状态，当前位作为新历史的第一位。 |
| 同上 | 已有时间锚点时，候选子帧必须同时满足起点标签增加 6000、12000 或 18000，SOW 相应增加 6、12 或 18 秒，FraID 相应按 1～5 循环；允许中间有两个子帧不能译码。 |
| 同上 | 连续接收 1200 位仍无有效子帧时，撤销 `frame_synced`、`anchor_valid` 和 `week_valid`。空闲时钟及上游暂停不消耗该保持期。 |
| `rtl/track/channel_slice.sv` | NH 同步失效时同步清除 D1，避免下游继续使用旧时间。 |

SOW 按 604800 秒回绕；D1 的 32 位码周期标签按无符号加法处理回绕。NH 标签回绕时重新搜索，不把回绕前后的 20 个相关结果混合。首个子帧仍由两处相隔 300 位、同极性的前导码及字段范围检查建立锚点；连续性约束用于后续子帧，不代表首次检出已完成多个连续子帧确认。

NH 接口无背压，每个 dump 后应至少留出 41 个空闲时钟完成相关和最坏情况下的相位判决。实际输入每个码周期约有 16368 个样本时钟，满足这一条件。帧译码复用 BCH 运算，正常 50 bit/s 输入为串行处理预留充足时间。

## 一条命令复现

在项目根目录运行：

```powershell
python scripts/gen_unit_vectors.py
python scripts/verify_sync_navigation.py
```

脚本调用实际 ModelSim 仿真，运行 7 项定向测试，保存独立工作库、完整日志、CSV、电文 BIN 和真实 WLF 波形。每次输出位于 `reports/sim/navigation/run_日期_时间/`，最近一次目录可查 `reports/sim/navigation/latest.json`。安装位置不在自动搜索范围时设置 `MODELSIM_HOME`。

双击该次输出目录中的 `open_wave.cmd` 打开波形；先看六个信号：

| 信号 | 观察方法 |
| --- | --- |
| `synced` | NH 位边界是否已找到；结尾故意注入不完整窗口，应回到 0。 |
| `bit_valid` / `bit_val` | 有效脉冲对应一个恢复出的数据位，其数值来自相关结果。 |
| `sf_valid` | 一个子帧完成译码时的单拍脉冲；本用例应出现 5 次。 |
| `sf_id` / `sf_sow` | 在 `sf_valid` 处读取子帧号与周内秒，不能把中途保持的旧值视为新电文。 |

需要解释纠错和反相时再看 `sf_fixes`、`sf_inverted`；解释时间有效性时看 `anchor_valid`、`week_valid`。联调输入是带确定性幅度扰动的 Prompt I，仍按 NH20 调制，没有提前把位判决结果传给接收模块。仿真将每个标称 1 ms 窗口压缩为 61 个时钟，横轴为加速后的仿真时间，实际码周期标签看 `dump_ms` 和 `bit_ms`。

## 回归覆盖

| 用例 | 检查内容 |
| --- | --- |
| `tb_nh_bit_sync`、`tb_nh_clear` | 保留原带噪位向量、数据位质量、结束元数据与清除行为。 |
| `tb_nh_continuity` | 全部 20 个 NH 相位；非零首标签；两种极性；扰动和最大有符号幅度；缺号、重复号、partial 后重获；零输入不误同步。 |
| `tb_d1_frame_sync`、`tb_d1_clear` | 保留原 5 子帧、BCH 单错、整体极性切换、50 个实测字结束时间、公共记录及译码末拍清除检查。 |
| `tb_d1_robustness` | 逐一翻转全部 285 个受保护发送位；校验信息、原始字和逐字纠错计数；输入中断、重复标签、SOW/FraID 不连续及越界、周内秒与标签回绕、两帧漏译、1200 位失效与重新捕获。 |
| `tb_sync_navigation` | 从 Prompt I 经 NH 同步、位判决到 D1 输出，核对 5 个子帧全部 224 位信息、正反极性、一次纠错和 50 个导航字的真实结束元数据；NH 失效后撤销下游时间。 |

若本地存在教师包，脚本调用其中的 `prompt_d1.decode_word`，独立复核联调输出的 50 个导航字、16 份新增子帧向量，并调用 `validate_teacher_records` 核对原电文用例的 50 条 NAVIGATION 和 1 条 END。教师工具不存在时记录“未执行独立检查”，不会把缺少工具写成已通过。

本次验证从 Prompt 级输入开始，不能替代射频采样、捕获和跟踪的全链路实验，也不能作为完整 100 s 六星 RTL 运行结果。BCH(15,11) 只保证单错纠正，多错可能误纠；本次连续性约束可以拒绝部分不一致电文，不能保证检出所有多错模式。尚未据此估计误同步概率或目标工艺的面积、时序。
