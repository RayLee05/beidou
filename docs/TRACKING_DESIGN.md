# 码跟踪与载波环当前设计

修订日期：2026-10-13；实现基线：2556e76。完整算法、公式和图表见 [码跟踪锁频锁相环报告](../deliverables/模块实验报告/02_码跟踪锁频锁相环报告.md)。

## 数据通路

`tracking_channel.sv` 连接载波混频 NCO、48 位码 NCO、码表、E／P／L 相关器和 `track_loop.sv`。每个被接受的样本推进一次相位；采样暂停时状态不消耗样本时间。载波 LUT 为 1024 项、10 位有符号幅值，I=x·cosθ，Q=−x·sinθ。相关累加为 26 位，以本地码回绕形成 dump，首个不完整窗口不更新环路。

内部码相位采用 Q11.37，周期 2046×2^37，标称每样本增量 2^34；兼容接口输出高 32 位 Q11.21。默认 E=P+0.5 chip、L=P−0.5 chip，DLL 反馈符号必须与此抽头定义一致。

## 归一化与鉴别器

Prompt 幅度采用近似模值、移位 3 的平滑及最小值 64，再以归一化尾数和 32 项倒数表形成约 4096 的标度。DLL 使用 E／L 幅度差；Costas PLL 根据 Ip 符号修正 Qp；FLL 使用相邻 Prompt 的叉积，以点积符号校正，首个有效窗口输出零。计算中各个截位点和饱和次序均由定点模型规定，不能简单替换为浮点表达式。

## 环路滤波与时序

| 项目 | 当前参数或行为 |
| --- | --- |
| DLL 系数 | Q8.8；比例 2099，积分 4 |
| DLL 积分限幅 | ±131072 |
| PLL 系数 | Q2.14；比例 6685，积分 134 |
| FLL 系数 | Q2.14；6685，受 fll_en 控制 |
| 载波积分限幅 | ±2883584 频率字，约 ±10.99 kHz |
| 载波辅助码率 | (facc×2749) 算术右移 16，加至 48 位码增量 |
| 运算资源 | 环路共享 28×17 乘法运算；载波辅助另含常数乘法 |
| 反馈延迟 | 完整窗口 j 的结果用于窗口 j+2 |
| 锁定判决 | 每 20 次完整更新，比较 Σabs(Ip) 与 2Σabs(Qp)，计数滞回 |

载波频率字包含标称 IF、载波积分和 PLL 比例项；码增量包含标称码率、载波辅助和 DLL 比例／积分项。乘法结果先按各支路规定移位，再累加或限幅，不使用未经实现的四舍五入假设。FLL 关闭时机属于具体配置，捕获定向用例在移交后 200 ms 关闭，并非整机默认自动切换策略。

## 实验与适用范围

300 ms PRN 20 定点用例在给定 0.3 chip 和 100 Hz 初始误差下产生 300 个 dump，16 字段共 4800 次比较全部一致，最终锁定。捕获移交用例检出 PRN 10 后运行闭环，300 ms 后码误差为 0.0058 chip。既有 100 s 六星浮点软件参考用于长期统计，与定点 RTL 用例分开列示；鉴别器 RMS 不作为真值相位或定位精度。

运行 `python scripts/run_rtl_unit.py tracking_channel --sim modelsim`；捕获移交运行 `python scripts/run_rtl_unit.py acquisition --sim modelsim`。新版输入的独立排列／背压检查由 `run_teacher_receiver.py` 自动先行执行。当前还需多通道全量公开 RTL、不同载噪比和动态条件、失锁统计及工艺面积／时序验证。
