# 需求清单（P0 基线 v0.1.0 · 待课程/ICD 冻结）

> 交付物对应「72 学时安排」第 1 行：**B1I 原理与任务分解 → 需求清单、组内计划**。
> 组内计划见 `PLAN.md`；每条需求在 `VERIFICATION_PLAN.md` 中有对应验证层与证据。
>
> 状态标记：**F** = 已由课程材料冻结；**P** = 待确认（不阻塞架构与定点设计，冻结前必须闭合）。
> 优先级：**M** = 必须；**S** = 应该；**O** = 可选扩展。

## 1. 范围

**范围内**：北斗 B1I；MEO/IGSO 的 D1 导航电文；离线 2 bit 实中频输入；共享样本流与公共时基；捕获、12 路跟踪、NH20/位同步、D1 帧同步与解调、测量记录；RINEX 3.05 OBS/NAV 软件适配；可综合 RTL 与 ASIC 前端/后端流程。

**范围外**：B1C/B2I/D2 信号；射频、天线、ADC 与真实硬件驱动；RTL 内浮点 PVT 或 RINEX 文本拼接；用模拟器真值填补缺失观测或星历。

来源缩写：**C-课程** = `集成电路EDA实验课_课程安排.pdf`；**C-基带** = `北斗B1I基带与位置解算基础.pdf`；**ICD** = 正式 B1I 接口控制文件（**当前未交付**）。
