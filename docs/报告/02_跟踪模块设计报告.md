# 跟踪模块设计报告

跟踪在捕获移交之后工作。每个码周期（1 ms，16368 个样本）输出 Early / Prompt / Late 的 I、Q，用这 6 个数更新载波 NCO 和码 NCO。环路在 `rtl/track/track_loop.sv`，每个完整窗口的 `dump` 触发一次更新。逐拍对照是 `sw/b1i_ref/tracking_model.py` 的 `LoopState.update()`。

采样率、中频和 2 bit 量化与教师公开输入约定相同。本节仿真仍用仓库向量，不是教师 100 秒场景。

## 1. 设计思路

码环和载波环都看 Prompt 附近的相关值。相关幅度随信号强弱变化，判别器如果直接用原始 I/Q，增益会跟着幅度走。所以先估计 Prompt 幅度，再把判别量归一化到大约 12 bit 满幅，环路增益用定点常数，不随这次相关值的大小改写。

更新不在每个样本上做。1 ms 积分结束后，一个 28×17 乘法器按步骤复用（S1 到 S12），算出下一窗口的频率字和码增量。通道在下一个码周期边界把 `pend_freq_word` / `pend_code_inc` 装进去。

载波用 Costas 鉴相加二阶环，并用相邻窗口的叉积做 FLL 辅助，用来拉较大的频率残差。码环用 E、L 幅度差。锁定不看单次相关，而看连续 20 ms 里 `|I|` 是否稳定大于 `|Q|`。

## 2. 方案

### 2.1 幅度与归一化

`magX = |I| + (|Q|>>1)`。幅度估计

```text
amp = have ? amp + ((magP-amp)>>>3) : magP
```

`>>>3` 是一阶平滑。归一化取 `amp` 的最高位位置 `L` 和其后 5 位尾数 `m`，查 `RECIP[m]`：

```text
norm(x) = (x * RECIP[m]) >>> (L+3)
```

归一化后满幅约 `2^12`（`NORM_W=12`）。

### 2.2 三个判别器

| 环 | 判别 | 含义 |
|---|---|---|
| PLL | `d_pll = sign(Ip)·Qp` | Costas，约 `4096·sinφ`。180° 模糊留给位同步和帧同步 |
| FLL | `d_fll = sign(dot)·cross >>> 12` | 相邻窗口叉积，约 `4096·sin(2π·Δf·T)`，`T=1 ms` |
| DLL | `d_dll = norm(magE - magL)` | 本地码超前时 Early 大于 Late，判别为正 |

`dot`、`cross` 由上一窗口和本窗口归一化后的 `Ip`、`Qp` 算出。第一个窗口还没有上一拍，FLL 判别记 0。

### 2.3 环路更新

默认增益在 `rtl/include/b1i_params.svh`：

| 系数 | 值 | 格式 |
|---|---:|---|
| PLL `Kp` / `Ki` | 6685 / 134 | Q2.14 |
| FLL `K` | 6685 | Q2.14 |
| DLL `Kp` / `Ki` | 2099 / 4 | Q8.8 |

```text
facc += (Ki·d_pll + Kf·d_fll) >>> 14
freq  = FREQ_WORD_IF + facc + (Kp·d_pll) >>> 14
dacc += (Ki·d_dll) >>> 8
inc   = NOM + (facc·2749) >>> 16 + (Kp·d_dll) >>> 8 + dacc
```

`FREQ_WORD_IF = 2^30`，正好是 `Fs/4 = 4.092 MHz`。`NOM = 2^34`，对应每码片 8 个样本。`(facc·2749)>>>16` 把载波多普勒折进码率（码多普勒援助）。`facc` 限在约 ±10.99 kHz，`dacc` 限在 ±131072。

锁定：每 `LOCK_BLOCK=20` 次更新比较 `Σ|Ip| > 2·Σ|Qp|`。成立则计数加 1，否则减 1。计数到 `LOCK_ON=5` 置锁定，回到 0 失锁。计数饱和在 10。

## 3. 仿真

### 3.1 与定点模型逐窗比对

`tb/system/tb_tracking_channel.sv` 的数据路径是：2 bit 字节流 → `sample_unpacker` → `tracking_channel`。每个码周期比对 E/P/L、码相位、下一窗口频率字、多普勒积分、锁定和三个判别器，与 `scripts/gen_track_vectors.py` 生成的期望值逐项相同。

向量 `tb/vectors/track_meta.json`：

| 项 | 值 |
|---|---|
| 码 | ICD 2.1，PRN 20 |
| C/N0 | 45 dB-Hz，噪声种子 7 |
| 长度 | 300 个窗口，1 227 600 字节 |
| 初始码相位误差 | +0.3 chip |
| 初始多普勒误差 | +100 Hz |
| t=0 多普勒真值 | −1443.22 Hz |
| 结束时模型锁定 | `final_locked=true` |

ModelSim SE-64 2020.4：300 个窗口全部一致，墙钟 8.13 s。2026-10-09 虚拟机 VCS I-2014.03 同一用例 `[PASS]`。

### 3.2 四星软件跟踪

`python scripts/run_local_chain.py --sec 7 --sats 4`，场景 7.0 s、C/N0=45 dB-Hz。这是定点模型整条链路，不是 `tb_tracking_channel` 那 300 个窗口。四颗星都锁定，各 6999 个窗口：

| PRN | 多普勒误差 (Hz) | DLL 判别 |
|---:|---:|---:|
| 34 | +0.61 | 888 |
| 35 | +0.09 | −83 |
| 9 | −0.67 | −229 |
| 23 | −0.19 | 27 |

多普勒误差最大约 0.67 Hz。

## 4. 结果分析

单通道 RTL 和定点模型在 300 ms、+0.3 chip、+100 Hz 初差下逐位相同。相同的范围包括相关值、码相位、频率字和锁定标志，不只是最后一刻的 `locked`。初差 100 Hz 比捕获细格残留（约 40 Hz，见捕获报告）更大，这条用例盖住了移交后环路要收的频率量级。

四星 7 秒结果里，多普勒误差都在 1 Hz 以内。码判别在 ±0.5 chip 时约为 `8192·τ`，PRN 34 的 DLL 判别 888，大约 0.11 chip，没有贴着限幅。

`reports/ref_model_results.md` 里另有一张短表（初差 +0.5 chip / +2 Hz，30 ms 时码误差仍约 −0.57 chip）。那是参考模型自检的一小段打印，不能当成这条 300 窗口用例已经收到 0。跟踪是否跟上，以第 3.1 节的逐窗比对为准。

## 5. 局限

- 逐位证据是单通道、300 ms、45 dB-Hz、ICD PRN 20。没有在教师 40 dB-Hz、100 秒六星文件上做 RTL 跟踪。
- 判别器已经按幅度归一化。更低 C/N0 的失锁和重捕没有在这组向量里统计。
- Costas 环的 180° 模糊不在跟踪里消除，由下一份报告的位同步和前导码处理。
