# 当前 RTL 定点格式与周期预算

修订日期：2026-10-13；实现基线：2556e76。当前 Fs=16.368 MHz、IF=4.092 MHz、码率 2.046 Mchip/s。早期 16.384 MHz 算式和统一 32 位码 NCO 描述已移除；机器预算脚本仍仅覆盖其实现的子项，不能替代本表或最终综合。

## 位宽与格式

| 数据或状态 | 当前实现 | 说明 |
| --- | --- | --- |
| 输入样本 | 3 位有符号 | 2 bit 映射为 −3、−1、+1、+3 |
| 载波相位 | 32 位 | 模 2^32；IF 字为 2^30 |
| 载波查表 | 10 位地址、10 位数据 | 1024 项；混频 13 位结果 |
| 码相位 | 48 位 Q11.37 | 模 2046×2^37；每样本标称增量 2^34 |
| 兼容码相位 | 高 32 位 Q11.21 | 不替代内部 48 位状态 |
| E／P／L I／Q | 各 26 位有符号 | 本地码回绕形成完整相关窗口 |
| NH 相关和／分数 | 32 位／40 位 | 最近 20 个 26 位 Prompt；候选绝对相关累计 |
| 鉴别器 | 16 位有符号饱和 | 归一化约 4096，实际移位见 track_loop |
| DLL／PLL 与 FLL 系数 | Q8.8／Q2.14 | 支路移位后按实现次序求和或限幅 |
| 真实样本计数 | 64 位 | valid／ready 握手时推进 |
| 公共记录 | 256 位 | 32 字节小端；TRACKING 版本 3 |

频率字分辨率为 Fs／2^32，约 0.003811 Hz。码 NCO 以 chip 为单位，码率与 Fs 之比恰为 1／8；48 位 Q11.37 的标称增量因此为 2^34。不能把载波的归一化模相位公式直接用于码周期结构。

## 标称窗口幅值上界

1 ms：N=16 368，abs(x)≤3，查表幅值≤512，绝对求和上界为 25 141 248，小于 26 位有符号正上限 33 554 431。20 ms 的求和上界为 502 824 960，30 位有符号数可覆盖，NH 运算使用 32 位。上述是标称窗口界，窗口长度受码环状态影响时须另查实际范围。

## 时序和状态预算

| 项目 | 逻辑数据量或节拍 |
| --- | --- |
| 1 ms／20 ms／1 s | 16 368／327 360／16 368 000 样本 |
| 6 s／30 s | 98 208 000／491 040 000 样本 |
| 捕获回放缓存 | 默认 33 024×3=99 072 bit |
| 每通道码表 | 2046 bit，捕获表另计 |
| 每通道相关状态 | 6×26 bit，其他状态另计 |
| 每通道 NH | 历史 20×26 bit；分数 20×40 bit |
| 每通道 D1 元数据 | 311×144=44 784 bit；12 路 537 408 bit |
| 环路反馈 | 窗口 j 的结果用于窗口 j+2；每通道内部串行运算 |

内部状态容量不等于综合面积，ROM／RAM 是否共享或映射为宏单元以目标工艺和综合结果为准。100 MHz 若用于预算，是尚未以目标工艺确认的分析时钟；在此假设下约 6.11 时钟／样本，不能据此宣称整机已达到实时吞吐。

## 截位与饱和

混频结果和相干相关按实现位宽保留。环路乘积采用实际算术右移，DLL 积分限幅 ±131072，载波积分限幅 ±2883584；不得用四舍五入或无限精度滤波器替换。载波辅助码增量使用常数乘法及右移，码 NCO 按码周期回绕。首次不完整 dump 不更新环路；暂停期间不增加样本计数。

参数见 `rtl/include/b1i_params.svh`，位宽和截位见 `rtl/track/track_loop.sv`、`code_nco.sv`、`carrier_mixer_nco.sv`。定点模型 `sw/b1i_ref/tracking_model.py` 与 300 ms RTL 用例的 4800 字段比较一致，适用范围限于该向量；详见 [跟踪报告](../模块实验报告/02_码跟踪锁频锁相环报告.md)。
