## 1. 结论摘要

| 项 | 结论 | 依据 |
|---|---|---|
| 样本位宽 | 3 bit 有符号（取值 −3..+3） | 2 bit 量化映射 |
| NCO 相位位宽 | **32 bit** | 频率分辨率 0.0038 Hz；IF 与码率均**精确可表示**，无截断误差 |
| 载波 LUT | 地址 10 bit、数据 10 bit 有符号 | 相位截断杂散 ≈ −60.2 dBc；幅度量化 SNR ≈ 62.0 dB |
| 混频乘积 | 13 bit（3 + 10，全精度不截位） | 最坏 3×512 = 1536 |
| 1 ms 相关累加 | **26 bit** 有符号 | 最坏 16384×3×512 = 25,165,824，26 bit 为精确最小位宽 |
| 20 ms 数据位累加 | 需求 30 bit，**实配 32 bit**（2 bit 裕量） | 最坏 503,316,480 |
| 环路系数 | Q2.14（16 bit） | 环路带宽与更新率待冻结 |
| 时基 | SAMPLE_INDEX 32 bit，回绕 262.144 s | 覆盖 ≥1 个 30 s D1 帧 |
| 目标时钟 | **100 MHz（占位，待冻结）** | 每样本 6.10 个时钟；1 样本/时钟仅占 16.38% |
| 乘法器 | 基准 24 个（12 通道 × I/Q 混频），393.2 MMAC/s | 复用方案见第 7 节 |
| 首版数据通路 | 方案 A：12 通道全并行，1 样本/时钟 | 累加器端口数是复用的真正瓶颈 |

## 2. 设计方法

1. **先定最坏情况边界，再定位宽**：所有累加器按合法输入的幅度上界推导，不做“统计上不会发生”的假设。
2. **能精确就不用近似**：选择使 IF 与码率归一化频率字为整数的相位位宽，消除频率截断误差。
3. **先量化再实现**：位宽、舍入与饱和策略在 P1 由定点模型与浮点模型对比验证，之后才固化 RTL。
4. **每一步可复算**：任何进入文档的数字必须来自脚本，且脚本打印参数 sha256 与 git revision。

## 4. NCO 定点设计

频率字定义为 `word = round(f / Fs × 2^W)`，相位累加器模 2^W 回绕。

| 频率 | 调谐字（W=32） | 精确 | 说明 |
|---|---:|---|---|
| IF 4.096 MHz | 1073741824 = 2^30 | ✅ | IF/Fs = 0.25，无截断误差 |
| 码率 2.046 MHz | 536346624 = 1023×2^19 | ✅ | 码率/Fs = 1023/8192，无截断误差 |
| 多普勒 ±10 kHz | ±2621440 | ✅ | 10 kHz/Fs = 5/8192 |

- **频率分辨率** = Fs/2^32 = 0.003814697 Hz，远优于 B1I 需要的毫赫兹级跟踪精度。
- **W=32 而非 28 的理由**：两者加法器面积差异可忽略，但 32 bit 让 IF 与码率**精确**表示；同时 32 bit 是常用的相位截断 LUT 接口宽度。
- **相位截断**：取高 10 bit 查表，最坏杂散约 −6.02×10 = −60.2 dBc；对 2 bit 输入量化（约 9.5 dB 量化 SNR 量级）完全可以接受。
- **LUT 数据 10 bit**：幅度量化 SNR ≈ 6.02×10 + 1.76 = 62.0 dB，同样远高于 2 bit 输入的信号质量。

> 说明：以上杂散/SNR 为解析估计，P1 阶段必须用定点模型做频谱仿真复核（`docs/VERIFICATION_PLAN.md` L0/L1）。

## 5. 累加器位宽推导

**1 ms 相干累加（E/P/L 各 I/Q 共 6 个）**

```
N = 16384 样本 ; |x| ≤ 3 ; |cos| ≤ 512
上界 = 16384 × 3 × 512 = 25,165,824 < 2^25 = 33,554,432
signed 25 bit 范围 ±16,777,216 → 不足 ; signed 26 bit 范围 ±33,554,432 → 刚好覆盖
```

- 结论：**CORR_ACC_W = 26**，为精确最小位宽，没有额外裕量（上界可由 +3 样本与满幅 cos 同时构造，属合法输入）。
- 若后续定点/浮点对比需要 2 bit 保护位，可提升到 28 bit，代价为 12 × 6 × 2 = 144 个触发器。

**20 ms 数据位累加（去 NH 后）**

```
上界 = 20 × 25,165,824 = 503,316,480 ; 需要 signed 30 bit
实配 BIT_ACC_W = 32（2 bit 裕量）
```

**状态量合计**：每通道 6×26 + 2×32 = 220 bit，12 通道共 2,640 bit（触发器），不构成面积瓶颈。

## 6. 时基、码相位与伪距分辨率

| 量 | 值 |
|---|---|
| 采样周期 | 61.035156 ns ↔ **18.2979 m**（1 个样本的时间误差） |
| 码片周期 | 488.7586 ns ↔ **146.5261 m** |
| 每码片样本数 | 16384 / 2046 = **8.007820** |
| SAMPLE_INDEX=32 bit 回绕 | 2^32 / 16.384 MSps = **262.144 s**（覆盖 ≥1 个 30 s 帧） |
| EPOCH_ID=32 bit 回绕 | 约 4.29×10^9 s（136 年） |
| 内部码相位 | 32 bit 归一化，约 2.4×10^−7 码片分辨率，测量时截取高位 |

码相位小数位与距离分辨率（1 chip = 146.53 m）：

| 小数位 | 分辨率（码片） | 分辨率（m） |
|---:|---:|---:|
| 6 | 1/64 | 2.2895 |
| 10 | 1/1024 | 0.1431 |
| 12 | 1/4096 | 0.0358 |
| 16 | 1/65536 | 0.0022 |

**结论**：测量记录中的分数码相位建议保留 **≥10 位小数**（0.14 m），若 RINEX 需更高精度可取 12–16 位；内部 NCO 保留全 32 bit 不受影响。

## 7. 周期预算

目标时钟 **100 MHz（占位）**，每样本可用 **6.1035** 个时钟；1 样本/时钟的数据通路只占用 **16.38%** 的时钟，其余时间可用于环路更新、记录输出与时间复用。

| 时间窗口 | 可用时钟 @100 MHz | 样本数 | 样本槽占用 | 环路更新机会 |
|---|---:|---:|---:|---:|
| 1 ms（积分/Prompt 边界） | 100,000 | 16,384 | 16.38% | 1 |
| 20 ms（1 个数据位） | 2,000,000 | 327,680 | 16.38% | 20 |
| 1 s（公共输出历元） | 100,000,000 | 16,384,000 | 16.38% | 1000 |
| 6 s（1 个子帧） | 600,000,000 | 98,304,000 | 16.38% | 6000 |
| 30 s（1 个 D1 帧） | 3,000,000,000 | 491,520,000 | 16.38% | 30000 |

- 每通道每 1 ms 的环路更新预算 **512 时钟**（占 0.512%），12 通道并行更新，余量充足。
- 约束关系：**目标时钟、面积预算与处理周期共同满足吞吐**（REQ-IMPL-003）。若目标时钟被压到 16.384 MHz，则 1 样本/时钟已无余量，必须提升并行度或压缩环路更新——这是必须在 M5 前冻结的接口参数。

## 8. 资源预算与复用方案取舍

- 每样本定点运算数（12 通道合计）= **132**（混频 2 + 累加 6 + 码抽头 3，按每通道 11 计）；总运算率 **2.163 Gop/s**。
- 基准乘法器：每通道 2 个混频乘 → **24 个**，MAC 率 **393.2 MMAC/s**。
- **真正的瓶颈是累加器端口**：每样本需要 12 × 6 = 72 次累加器读写，在 6.10 时钟/样本下相当于 **11.80 次/时钟**。

| 方案 | 复用因子 | 乘法器 | 需要时钟 | 可行（100 MHz） | 说明 |
|---|---:|---:|---:|:--:|---|
| A | 1 | 24 | 16.384 MHz | ✅ | 全并行，状态全在触发器 |
| B | 2 | 12 | 32.768 MHz | ✅ | 每 2 通道共享混频乘法器 |
| C | 3 | 8 | 49.152 MHz | ✅ | 每 3 通道共享；累加器需多端口 |
| D | 6 | 4 | 98.304 MHz | ✅ | 每 6 通道共享；端口压力最大 |

**决策**：首版采用**方案 A**。理由：

1. 复用省下的是乘法器，但累加器端口数随复用线性增长，多端口寄存器堆的面积/功耗代价通常超过省下的乘法器；
2. 全并行让每个通道状态独立，故障可用波形逐通道定位，符合“先正确、后优化”；
3. 100 MHz 下方案 A 的时钟占用仅 16.38%，面积优化的收益留到 M5 综合后再评估（课程也要求至少一项设计比较，这正好是候选题目）。

## 9. 舍入、饱和与复位策略

| 位置 | 策略 |
|---|---|
| NCO 相位累加 | 模 2^W 自然回绕，属定义行为，不产生未定义状态 |
| LUT 寻址 | 取相位高 CARR_LUT_ADDR_W 位（截断），误差计入杂散预算 |
| 混频乘积 | 13 bit 全精度保留，不截位 |
| 1 ms 相关累加 | 26 bit 全精度，不截断；1 ms 边界清零，与 sample_valid 同步 |
| 20 ms 数据位合并 | 32 bit 全精度；NH 符号按位同步结果去除；数据位极性由 \|I\| 判定后丢弃符号 |
| 环路滤波系数 | Q2.14；乘积累加后右移 14 位，就近舍入（round-half-up） |
| 环路输出频率字 | 32 bit 有符号；越界饱和到 ±(2^31−1) 并置 fault，禁止回绕 |
| 码相位 | 32 bit；到达 2046 chip 边界回绕并递增整周期计数 |
| 复位 | 异步复位同步释放；复位后所有 valid 为 0，禁止用 0 当作合法测量 |

## 10. 定点—浮点误差预算与验证方法（P1 执行）

1. 用 Python 浮点模型生成参考 Prompt/E/P/L/码相位/多普勒序列。
2. 用定点模型（按本文件位宽与舍入策略）逐步量化，逐 1 ms 比对：
   - 码相位误差应远小于 1 个采样间隔（≤ 1/8 码片目标）；
   - 多普勒误差应小于 PLL 带宽的 1%；
   - 相关幅值相对误差应小于 1%（26 bit 累加理论上限远大于实际，误差主要来自 LUT 量化）。
3. 对每个截位/舍入点做单独对比，定位误差来源，而不是只看最终结果。
4. 误差预算表与曲线进入 `reports/`，作为 M2 出口条件的一部分。

## 11. 待确认项

1. **目标时钟频率、工艺与标准单元库**未给定 —— 100 MHz 为占位值，冻结后必须重跑 `fixed_point_budget.py`。
2. **IF/Fs 冲突**（4.096 MHz/16.384 MSps vs 4.092 MHz/16.368 MSps）会改变调谐字与码相位归一化，须书面确认。
3. **捕获搜索范围/步长**决定捕获引擎周期与面积预算，当前仅为起始建议。
4. **环路带宽与积分时长**未冻结，影响系数位宽、锁定门限与误差预算目标值。
