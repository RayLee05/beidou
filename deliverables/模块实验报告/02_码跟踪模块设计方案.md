# 北斗 B1I 码跟踪模块设计方案

本方案说明完整接收机跟踪通道的码环、锁频环和锁相环，并单列单星跟踪的接入方式与观测量。仿真截图和逐毫秒数值见配套实验报告。

## 1 设计目标与输入条件

跟踪通道在捕获给出的码相位和多普勒初值上，持续估计载波频率、载波相位和测距码相位。每个本地码周期输出一组 Prompt 相关值，供后面的 NH 同步和导航电文解调使用。

一个通道内同时放 DLL、FLL 和 Costas PLL。幅度先做归一化，减轻输入功率变化对鉴别器增益的影响。载波频率估计再辅助码率，补偿多普勒带来的码片率变化。顶层可以把该通道复制为 12 路，各通道的环路状态互不共享。

| 参数 | 设计设置 |
|---|---|
| 采样率与中频 | 16.368 MHz；4.092 MHz |
| 码率与码长 | 2.046 Mchip/s；2046 chip |
| 积分边界 | 本地码 NCO 回绕；标称约 1 ms |
| E／L 间隔 | 相对 Prompt ±0.5 chip |
| 输入样本 | 3 位有符号数 |
| 环路系数 | 使用 `b1i_params.svh` 中的默认值 |

通道只根据有效样本、已装入的本地码和初始状态工作。合成向量的真值、教师信号源的 `dbg_*` 都留在测试台，不进入环路。

## 2 通道结构与数据表示

`tracking_channel.sv` 按载波混频、码 NCO、码 RAM、E／P／L 相关器、`track_loop.sv` 的顺序连接。每个被接受的样本推进一次载波相位和码相位。`sample_valid` 为 0 时，相位、累加器和窗口计数都保持，不按墙钟消耗样本。

| 对象 | 表示与用途 |
|---|---|
| 载波 NCO | 32 位相位累加器。频率字 W 对应 W·Fs／2³² Hz |
| 载波查表与混频 | 1024 点、10 位正弦／余弦。I = x·cosθ，Q = −x·sinθ。乘积 13 位，不截位 |
| 码 NCO | 48 位 Q11.37。一个码周期为 2046×2³⁷。标称每样本增量 2³⁴ |
| 对外码相位 | 内部相位取高 32 位，表示 Q11.21 |
| 相关累加器 | E／P／L 各有 I、Q 两路，共 6 路 26 位有符号累加 |
| 环路乘法器 | 共享一个 28×17 有符号乘法器，按步骤复用 |

默认抽头为 E = P + 0.5 chip、L = P − 0.5 chip，间隔由 `code_spacing` 给出，单位是 1／8 chip，默认值为 4。DLL 的反馈符号与这一抽头方向绑在一起。交换 Early 和 Late 的命名后，不能沿用同一套正号。

## 3 码跟踪环

### 3.1 相关幅度与归一化

环路内部用近似模值代替平方和开方：

MX = |IX| + |QX|／2

Prompt 幅度再用移位为 3 的指数平滑。第一个完整窗口直接取该窗口的幅度，之后

Âk = Âk−1 + (MP,k − Âk−1)／8

平滑幅度低于 64 时，归一化分母按 64 计算，避免弱信号或零输入把倒数放大到溢出。硬件用平滑幅度的最高有效位和 5 位尾数查 32 项倒数表，乘完后再按指数右移，结果饱和到 16 位。归一化满幅标度约为 4096。这是有限精度倒数，不是精确除法。

### 3.2 DLL 鉴别与码增量

dDLL = norm(ME − ML)

Early 幅度大于 Late 时，鉴别器为正，表示本地码偏晚，需要加快码 NCO。比例项和积分项都以正号加到码增量上。

码增量写成

ucode = 2³⁴ + uaid + uDLL,P + uDLL,I

DLL 比例系数 2099、积分系数 4，都按 Q8.8 解释，乘完后算术右移 8 位。积分状态限幅在 ±131072。载波辅助项把多普勒积分字乘以 2749，再算术右移 16 位，加到 48 位码增量上。码相位只在有效样本上更新。

| 环路项 | 默认整数系数 | 定点格式 |
|---|---|---|
| DLL 比例／积分 | 2099／4 | Q8.8 |
| PLL 比例／积分 | 6685／134 | Q2.14 |
| FLL 辅助 | 6685 | Q2.14 |
| 归一化输出 | 约 4096 | 16 位有符号，满幅标度 12 位 |

## 4 锁频环与锁相环

### 4.1 FLL

FLL 用相邻两个完整 Prompt 窗口的归一化 I、Q 做叉积和点积：

Ck = Ik−1 Qk − Ik Qk−1

Dk = Ik−1 Ik + Qk−1 Qk

dFLL = sat16[ sgn(Dk) · Ck ／ 2¹² ]

点积的符号用来校正数据比特和 NH 码造成的 180° 翻转，避免频率鉴别器跟着符号来回拉。第一个完整窗口没有上一窗，FLL 输出 0。鉴别结果是归一化定点量，不是直接的赫兹误差。`fll_en` 为 0 时，这一项不加入载波积分器。整机默认保持使能；个别捕获移交用例在跟踪 200 ms 后关闭，那是用例配置，不是通道里的自动切换。

### 4.2 Costas PLL

dPLL = sgn(Ik) · Qk

I 大于或等于 0 时符号取 +1，否则取 −1。这样数据位的整体反相不会把鉴相方向带反，但载波仍有 180° 相位模糊，极性留到后面的导航前导码确定。

PLL 积分项和 FLL 辅助项各自乘系数、算术右移 14 位，再加到载波频率积分器。各支路先截断再相加，与定点参考 `tracking_model.py` 一致。载波频率字为

W = 2³⁰ + facc + uPLL,P

其中 2³⁰ 是中频字，对应 4.092 MHz。`facc` 限幅在 ±2883584，约 ±10.99 kHz。整数系数的量纲同时取决于鉴别器标度和频率字分辨率，不能直接当成模拟环路带宽。

## 5 更新时序与锁定标志

共享乘法器按步骤 1 到 13 做归一化和滤波，然后回到空闲。窗口 j 的观测量在该窗口结束后计算，在下一次码周期边界装入 NCO，作用于窗口 j+2。当前边界不对新系数做旁路。

`init_load` 只持续一个时钟。装载拍不推进相位，并把载波积分字置成给定的初始多普勒，清零码积分、锁定计数和上一窗相关值。装载后的第一个窗口不满一个码周期，`dump_partial` 为 1，dump 照常送出，环路不更新。

锁定检测每累计 20 个完整更新，比较 Σ|Ip| 与 2Σ|Qp|。满足时计数加 1，否则减 1，计数范围 0～10。计数达到 5 后置 `locked`，回到 0 才清锁。该标志给通道管理用，不能单独说明码已经对准、载波已经锁定，或导航电文有效。

## 6 实现约束

定点截断、饱和和两拍更新延迟都写在 RTL 里，并用 `tracking_model.py` 逐字段对照。浮点软件的反正切鉴别和另一套环路调度不能逐拍等同于这份定点实现。

当前系数面向捕获移交后的牵入和稳态跟踪。不同载噪比、码频初差和频率变化率下的牵入时间、失锁概率，需要单独统计。持续打开 FLL 与牵入后关闭 FLL，也要按信号结果决定，不在通道里写死切换时刻。面积、时序和上板测量不在本方案的范围内。

单通道闭环的文件位置如下。

| 功能 | 文件 |
|---|---|
| 单通道集成 | `rtl/track/tracking_channel.sv` |
| DLL、FLL、PLL 与锁定计数 | `rtl/track/track_loop.sv` |
| 载波 NCO 与码 NCO | `rtl/track/carrier_mixer_nco.sv`、`rtl/track/code_nco.sv` |
| 码 RAM 与相关器 | `rtl/track/code_ram.sv`、`rtl/track/correlator_epl.sv` |
| 参数与载波表 | `rtl/include/b1i_params.svh`、`rtl/common/carrier_lut.sv` |
| 定点参考 | `sw/b1i_ref/tracking_model.py` |

## 附录 单星跟踪接入

### A.1 接入目标

单星跟踪把教师带多普勒信号源接到现有 `tracking_channel`，用来看码环和载波环怎样消化已知的初始误差。卫星编号、多普勒和码率都由信号源固定。原通道的 E／P／L 相关、DLL、FLL 和 Costas PLL 不改。

这一接法一次只跟踪一颗星，便于对照每个 1 ms 的相关幅度和频率字。搜索其余卫星、频率不确定度和捕获移交仍由原捕获引擎承担。

| 项目 | 设计输入与约束 |
|---|---|
| 信号源 | `bdi_signal_source_doppler`；PRN 6 |
| 采样与中频 | 16.368 MHz；4.092 MHz |
| 载波多普勒 | +250 Hz，频控字 65600 |
| 码多普勒频控字 | 86，约 +0.33 Hz |
| 样本 | 有符号 2 bit：01 为 +1，00 为 0，11 为 −1；符号扩展成 3 位后送入通道 |
| 初始码相位 | 相对发送相位 10 超前 0.15 chip |
| 初始多普勒字 | 39360，约 +150 Hz，比信号源低约 100 Hz |
| 环路 | E／L 间隔 0.5 chip；FLL 保持使能；系数用默认值 |

2 位编码与公开 IF2 的四电平不同，00 必须当作 0。默认参数在一次仿真里保持不变。

### A.2 数据边界与启动顺序

接收机只接 `if_sample` 和 `if_valid`。信号源的 `dbg_*` 端口悬空，不接进相关器、NCO 或环路。本地码由共用的 `prn_code_gen` 生成 PRN 6，写入通道码 RAM，不读取教师源里的码表。

启动顺序是：复位；写完码表；给 `init_load` 一个时钟，装入初始码相位、载波相位 0 和多普勒字 39360；再释放信号源复位。信号源先空出 4 个码片，这段 `if_valid` 为 0，通道不推进。第一个有效样本才是积分的时间起点。

装载后的第一个窗口不满 1 ms。该窗口的 dump 可以观察，环路不把它算进更新。此后每个完整窗口的结果在再下一个码周期边界生效。

### A.3 初始相位怎么摆

发送相位 10 与单星捕获读到的相位一致。0.15 chip 的超前量直接加在 48 位码相位的小数上，同时减去即将使用的码增量，使第一个有效样本的相位落在这个偏差上。码增量里已经含有初始多普勒 39360 对应的载波辅助项。

这样第一个完整积分就能看到 Early 与 Late 的不平衡，同时载波环要从约 150 Hz 拉向 250 Hz。初始多普勒字装在 `facc` 里，频率字从中频字 2³⁰ 加上该字开始。

### A.4 观测量

环路内部的幅度仍是 |I| + |Q|／2，鉴别器仍是第 3、4 节的定点式。测试台另外用相关器原始 I、Q 做两组千分比，只用于观察和判定，不反馈回通道。

- 观察幅度取 |I| + |Q|。它和环路内部的近似模值不是同一个数。
- `el_permille = |E − L| × 1000 / (E + L)`。100 表示两侧相差 10%。
- `iq_permille = |Q| × 1000 / (|I| + 1)`。100 表示正交分量约为同相分量的 10%。
- 载波看多普勒字 `facc`。65600 对应约 249.99 Hz。把字截成整数赫兹时可能得到 249，判定以字为准，容差 3936，约 15 Hz。

同一 1 ms 里，Prompt 高于 Early 和 Late、`el_permille` 小于 100、`iq_permille` 小于 100、多普勒字落在容差内，才算这一毫秒跟踪到位。`locked` 可以同时显示，不能代替这四项。

Prompt 的 I 会随 NH 码和导航比特改变符号。Costas 和 FLL 都用符号校正，幅度和 `iq_permille` 不随这次翻转改变。

### A.5 接口与波形里看什么

| 信号 | 含义 |
|---|---|
| `if_sample`、`if_valid` | 唯一进入通道的信号源输出 |
| `dump_valid`、`dump_partial` | 积分结束；`dump_partial` 为 1 的窗口不更新环路 |
| `i_p`、`q_p` 及 E／L 的 I、Q | 原始相关累加，观察幅度由它们取绝对值后相加 |
| `d_dll`、`d_pll`、`d_fll` | 三个鉴别器的 16 位定点输出 |
| `dop_word`、`freq_word` | 载波积分字，以及中频字加积分字再加 PLL 比例项 |
| `locked` | 第 5 节的滞回标志，只作辅助 |

`freq_word` 用十六进制看。它的主体是中频字 `0x40000000`，多普勒只占低位，换成模拟刻度后看不出 250 Hz。

### A.6 适用范围

本接入只覆盖 PRN 6、无噪声、载波多普勒固定为 +250 Hz 的一次输入。它说明现有通道能够从 0.15 chip 码误差和约 100 Hz 频率误差上闭合，不代替多星、低载噪比或动态多普勒下的统计。门限和容差写在测试台里，通道本身不做除法判决。

实现讲解可依次看 `tracking_channel.sv` 的装载与 `dump_partial`，`track_loop.sv` 的幅度、三个鉴别器和 `pend_freq_word`，以及 `code_nco.sv` 的回绕。仿真入口、通过条件和五张波形见 `02_码跟踪实验报告`。
