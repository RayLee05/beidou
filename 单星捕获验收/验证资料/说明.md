# 这些文件是什么

- `capture.csv`：每算完一轮保存一行，记录位置、能量和捕获结果。
- `result.json`：一键脚本自动核对的结果，包含能量比和本次源文件的校验值。
- `wave_segments.csv`：从实际 ModelSim 波形文件中导出的两段码线，用于绘制讲解提纲中的对比图。

完整波形体积较大，每次双击“打开验收波形.cmd”时重新生成，保存在 `reports/sim/single_sat_demo/` 下各次运行的目录中。

图表需要更新时，先运行一键仿真，再在项目根目录运行 `python scripts/plot_single_sat_demo.py`。此绘图脚本需要 ReportLab 和 PyMuPDF；平时打开验收波形不需要 Python。
