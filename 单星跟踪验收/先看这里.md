# 单星跟踪验收

在本目录打开 PowerShell，运行：

```powershell
.\run_demo.ps1
```

脚本用 ModelSim 把学生包里的带多普勒 BDI 信号源接到现有 `tracking_channel`，仿真 640 ms，然后打开波形。只要结果，加 `-NoGui`。

接收机只使用 `if_sample` 和 `if_valid`。信号源的 `dbg_*` 没有接入跟踪电路。

## 这次故意留下的初始误差

- 码相位比发送相位 10 超前 0.15 chip。第一个完整 1 ms 积分的 `el_permille` 应大于 100。
- 载波多普勒字从 39360（约 +150 Hz）拉到 65600（+250 Hz）。频率字稳态在 `0x40010040` 附近，也就是中频 `0x40000000` 再加上这 250 Hz。
- E/L 间隔是默认的 0.5 chip。FLL 开着，环路系数用设计默认值。

## 波形里看什么

时间轴是 ms。`el_permille` 和 `iq_permille` 的单位是千分比，100 就是 10%。

| 分组 | 信号 | 稳态 |
|---|---|---|
| 1 Input | `if_valid`、`if_sample`、`dump_valid` | 预热 4 个码片后 `if_valid` 为 1；`dump_valid` 约每 1 ms 一个脉冲 |
| 2 Code loop | `mag_e`、`mag_p`、`mag_l`、`el_permille`、`d_dll` | Prompt 最高，Early 与 Late 接近，`el_permille` < 100，`d_dll` 在 0 附近 |
| 3 Carrier loop | `i_p`、`q_p`、`iq_permille`、`d_pll`、`dop_word`、`dop_hz`、`freq_word` | `iq_permille` < 100，`dop_hz` 在 250 附近，`dop_word` 在 65600 附近 |
| 4 State | `locked`、`full_dumps` | 锁定标志只作辅助，不能单独当作跟踪成功 |

建议缩放：

1. 0–40 ms：码误差和载波误差从初始偏差开始下降。
2. 前 300 ms：`dop_word` 从 39360 走向 65600。
3. 0–640 ms：码环在约 +0.33 Hz 码多普勒下保持 Prompt 居中。370–382 ms 附近 `el_permille` 会短时间抬起，随后回到 0。
4. 540–640 ms：同一窗口里 Prompt 最高，并且 `|I|` 明显大于 `|Q|`。

`dop_hz` 是频率字截成整数后的赫兹，65600 对应的真值约 249.99 Hz，所以这里可能显示 249 或 250。判定用的是频率字，容差 15 Hz。

通过时日志里有 `PASS: single satellite tracking`。每个 1 ms 的记录在 `reports/sim/single_sat_track/track.csv`。
